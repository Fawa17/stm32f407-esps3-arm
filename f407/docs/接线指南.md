**三条铁律**

1. **舵机电源独立**，绝不从 STM32 板子的 3.3V/5V 引脚取电。6 个舵机同时动作的堵转电流可达 4~6A。
2. **必须共地**：舵机电源 GND、STM32 GND、MPU6050 GND、OLED GND、ESP32-S3 GND 全部接在一起。
3. **先接信号线，后上电**；上电顺序：舵机电源 → STM32 → ESP32-S3。

## 2. 逐条接线表

### 2.1 六路舵机（PWM，3.3V 逻辑）

| 轴 | 关节 | STM32 引脚 | 定时器通道 | 舵机线（常见配色） |
|---|---|---|---|---|
| 0 | 底座旋转 | **PA0** | TIM2_CH1 | 橙/白 = 信号 |
| 1 | 大臂俯仰 | **PA1** | TIM2_CH2 | 红 = +5V |
| 2 | 小臂俯仰 | **PA2** | TIM2_CH3 | 棕/黑 = GND |
| 3 | 腕部俯仰 | **PA3** | TIM2_CH4 | |
| 4 | 腕部旋转 | **PA6** | TIM3_CH1 | |
| 5 | 夹爪开合 | **PA7** | TIM3_CH2 | |

- 六路信号线接在 STM32 的 **PA0 / PA1 / PA2 / PA3 / PA6 / PA7**，顺序与轴号一一对应。
- 舵机 +5V 全部并接到外部 5V 电源正极；GND 全部并接到外部电源负极（并与 STM32 GND 相连）。
- 每个舵机的电源脚附近并联一个 **0.1µF** 瓷片电容（可选，抑制抖动）。
- PWM 频率 50Hz（20ms），脉宽 500~2500µs 对应 0°~180°。

### 2.2 MPU6050（I2C2，3.3V）

| MPU6050 | STM32 | 说明 |
|---|---|---|
| VCC | **3.3V** | 不要接 5V |
| GND | GND | |
| SCL | **PB10** | I2C2_SCL，AF4 |
| SDA | **PB11** | I2C2_SDA，AF4 |
| AD0 | GND | 地址 0x68（接 3.3V 则 0x69） |
| INT | 不接 | 固件轮询，不用中断 |
| XDA/XCL | 不接 | |

- 模块自带 4.7k 上拉一般够用；若线长 >20cm 或读不到，可在 SCL/SDA 各加 2.2k~4.7k 上拉到 3.3V。

### 2.3 OLED 0.96"（I2C1，3.3V）

| OLED | STM32 | 说明 |
|---|---|---|
| VCC | **3.3V** | |
| GND | GND | |
| SCL | **PB6** | I2C1_SCL，AF4 |
| SDA | **PB7** | I2C1_SDA，AF4 |

- 固件会自动探测 `0x78` 和 `0x7A` 两个地址，两种模块都支持。
- 如果整幅画面右移 2 像素、右边 2 列花屏 → 是 SH1106 屏，把 `OLED.c` 里的 `OLED_SH1106` 改成 `1` 重新编译。

### 2.4 ESP32-S3（串口链路）

| ESP32-S3 | STM32 | 说明 |
|---|---|---|
| GPIO17（TX） | **PA10**（USART1_RX） | 交叉连接 |
| GPIO18（RX） | **PA9**（USART1_TX） | 交叉连接 |
| GND | GND | 必须共地 |
| 3V3 / 5V | 独立供电 | 建议 5V 供电口，或用 USB 供电 |

- 波特率 115200 8N1。
- **TX/RX 必须交叉**：S3 的 TX 接 STM32 的 RX，反之亦然。接反了的现象是"网页显示链路离线、发指令没反应"。
- S3 板载 USB 可以直接烧固件（`C:\STM32\hand_s3\build.bat flash <COM号>`），不用 USB-TTL。

### 2.5 调试串口（可选）

| STM32 | 用途 |
|---|---|
| PD8 = USART3_TX | 接 USB-TTL 的 RX，115200，可打印日志 |
| PD9 = USART3_RX | 接 USB-TTL 的 TX |

### 2.6 下载与调试

| STM32 | ST-Link |
|---|---|
| PA13 = SWDIO | SWDIO |
| PA14 = SWCLK | SWCLK |
| GND | GND |
| 3.3V | 3.3V（可选，板子已供电时不接） |

- Keil → Options → Debug → ST-Link Debugger → Port 选 **SW**；Flash Download 勾 Reset and Run。
- 烧完自动运行，OLED 应在 1~2 秒内亮起。

## 3. 电源分配建议

| 负载 | 电压 | 典型电流 | 峰值 |
|---|---|---|---|
| 6× 舵机（SG90 类） | 5V | 6×100mA = 0.6A | 6×700mA ≈ 4.2A |
| 6× 舵机（MG996R 类） | 6V | 6×200mA = 1.2A | 6×2.5A ≈ 15A ⚠ |
| STM32F407 板 | 5V | 80mA | 120mA |
| ESP32-S3 | 5V | 120mA | 500mA（WiFi 发射） |
| MPU6050 | 3.3V | 4mA | 5mA |
| OLED | 3.3V | 20mA | 30mA |

- 建议：**5V/6A 开关电源**供舵机，STM32 与 S3 用另一个 5V/1A 电源或 USB。
- 舵机电源入口并 **1000µF/16V 电解电容** + 每路 0.1µF 瓷片。
- 大电流舵机（MG996R）建议单独配 6V/10A 电源，且**不要与 MCU 共用一条细线**。

## 4. 上电检查清单

按顺序做，每一步都确认后再继续：

1. **断电**测通断：所有 GND 是否连通（用一个万用表二极管档，蜂鸣即通）。
2. **断电**测短路：5V 对 GND、3.3V 对 GND 不应蜂鸣。
3. 只接 STM32（不接舵机、不接外设），USB 供电，确认 3.3V 正常、能下载程序。
4. 接 MPU6050 + OLED，上电看 OLED 是否亮、显示 `ARM LINK:...`。如果不亮，先查 OLED 的 PB6/PB7。
5. 接 ESP32-S3，网页打开 `http://172.19.62.150/`，看「链路」是否显示在线。
6. **只接 1 个舵机**（底座，PA0）到外部 5V，上电：应看到它缓慢回到 90° 中位，而不是猛跳。
7. 逐个增加舵机，每加一个观察电源电压是否跌落（低于 4.6V 就要换电源/加电容）。
8. 六个都接好后再测网页控制。

## 5. 常见故障对照

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 舵机乱抖、STM32 重启 | 舵机电源与 MCU 共线，电压跌落 | 独立 5V 电源 + 大电容 + 共地 |
| 某个舵机不动 | 该轴信号线接错/没接 | 对照第 2.1 节表，检查该轴引脚 |
| 六个舵机全不动 | TIM2/TIM3 未启动，或舵机没供电 | 量舵机电源；看 OLED 是否有 `B090` 等 |
| 舵机转向反了 | 该关节安装方向相反 | 调 `RobotArm_SetReverse(轴号, 1)` 或改 IK 的 sign |
| OLED 黑屏 | 地址不对 / 引脚不是 PB6/PB7 | 换地址自动探测；确认 SDA/SCL 没接反 |
| OLED 花屏、右移 2 像素 | 是 SH1106 控制器 | `OLED.c` 里 `OLED_SH1106` 改 1 |
| 网页显示链路离线 | S3 的 TX/RX 接反或没共地 | 交叉接线 + 共地；看 S3 串口日志 |
| 网页能开但发指令不动 | 没切到远程模式 | 点「远程模式」，或发 `{"mode":1}` |
| MPU6050 初始化失败 | 3.3V 供电/地址/上拉 | 量电压；AD0 接 GND；加上拉电阻 |
| 机械臂动作方向与预期相反 | 关节零位/方向与模型不一致 | 用 `/api/jog?axis=&deg=` 逐轴标定 |
